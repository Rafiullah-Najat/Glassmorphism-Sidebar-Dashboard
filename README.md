# 🍎 Glassmorphism Sidebar Dashboard

A modern and responsive **Glassmorphism Sidebar Dashboard** built with **HTML, CSS, and JavaScript**.
The project features a glass-style UI, interactive navigation menu, profile section, and statistics cards.
---
## ✨ Features

* 🪟 Glassmorphism UI design
* 📱 Responsive dashboard layout
* 🍎 Apple-inspired sidebar
* 🧭 Interactive navigation menu
* 📊 Statistics cards
* 👤 User profile section
* 🎨 CSS gradient background
* ✨ Hover and transition effects
* 🔵 Active menu indicator
* ⚡ Pure HTML, CSS & JavaScript
